# First upload: GitHub Desktop

1. Install GitHub Desktop and sign into your GitHub account.
2. File > Clone repository > `balcony3232/Viora` and choose a local folder.
3. Copy the contents of this Viora-v0.9.1 project folder INTO the cloned repository folder.
   Be sure to include hidden `.github` and `.gitignore` (Windows may hide dotfolders).
4. Check the Changes list: source code, assets, workflow, docs only.
   **Never** include your AppData folder, local account, settings or private backups.
5. Commit as `Viora v0.9.1 UI clarity and splash quality` and click Push origin.
6. Open repository Actions and run `Windows EXE build and release` manually.
7. Test the resulting executable before pushing the `v0.9.1` release tag.
