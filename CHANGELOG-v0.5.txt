VIOLETSTRAP v0.5 — PERSONALISATION / EXPLORER / STATISTICS

NEW — APPEARANCE
- Appearance page with Violet, Amethyst, Midnight, Rose and Emerald dark palettes.
- Accent colour, surfaces, sidebar and nav selection react to the selected palette.
- All main/secondary action buttons use the chosen accent family.
- Optional reduced-motion setting disables new subtle 160 ms page fade transitions.
- Local profile-picture upload (PNG/JPEG, max 5 MB) for the dashboard/sidebar/appearance preview.
- Reset to the default Violetstrap diamond icon at any time.
- Refined diamond logo embedded into the Windows application icon, splash screen and sidebar.
- The pre-existing custom splash background controls are also accessible from Appearance.

IMPROVED — FASTFLAG EXPLORER
- Boolean flags use an On/Off dropdown rather than a free-text field.
- Integer flags retain input validation; unknown reference flags remain read-only.
- 'My flags' filter displays configured flags in the active profile.
- Filter results show matching-entry count and configured-entry count.
- Clear Search resets query, category and My flags filter.
- Flag values still save to a profile until the user explicitly applies that profile.
- Roblox's allowlist restrictions are unchanged. This is not an FPS unlocker.

IMPROVED — STATISTICS
- New cards for today's observed runtime, past-seven-day runtime and current activity streak.
- Change chart range between seven and thirty days (scrollable for thirty).
- Records up to 250 completed *observed* sessions, with start, measured duration, and
  best-effort experience name, when game-name sharing is enabled.
- Export locally observed totals, day-by-day runtime and completed session history to CSV.
- v0.4's total statistics and daily records remain compatible; session history starts
  when v0.5 is installed. Violetstrap must be open to monitor Roblox.

IMPROVED — DISCORD
- Optional 'browsing Roblox' Rich Presence state when Roblox Player is closed.
- Reads only the title of the currently active browser window; supported browser process
  names include Chrome, Edge, Firefox, Brave and Opera. NO history/URL/tab scanning.
- Browser-detection option is off by default and must be explicitly saved.
- Better reconnect behaviour after signing out of and back into Violetstrap.
- Existing playing, AFK, background, game title and elapsed-time functionality retained.

MIGRATION / SAFETY
- Account, passwords, presets, profiles, Rich Presence application ID, splash and
  existing statistics use the same %LOCALAPPDATA%\Violetstrap location as v0.4.
- First launch makes a best-effort untouched copy: settings-before-v0.5.json.
- No Roblox credentials, cookies or Discord bot tokens needed.
- No client injection or anti-cheat bypass introduced.
- Read-only reference flags remain read-only; unsupported values are not written.

TESTING LIMITATIONS
- Tested source-level XML parsing, named control uniqueness, handler references,
  JSON parse and ZIP contents in a non-Windows environment.
- NOT compiled or run on Windows here. Build with the .NET 8 Windows SDK / WPF.
- The browsing state is a heuristic and may miss or misidentify Roblox-titled pages.
- Roblox can change FastFlag support and client log formats at any time.
