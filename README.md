# Viora

Viora is an **unofficial personal Roblox companion for Windows**, formerly called Violetstrap.

The upcoming **v0.9.0** source contains a redesigned dark-purple V brand, FastFlag Explorer, profiles, Roblox activity tracking, game favourites, opt-in Discord Rich Presence, GIF splash screens and backup/recovery tools.

The source and build workflow are being prepared for the initial upload. **No Windows executable or GitHub Release has been published yet.**

This repository must never contain local profile/account data, `settings.json`, `local-account.json`, personal activity statistics, custom user media or files from `%LOCALAPPDATA%\Violetstrap` / `%LOCALAPPDATA%\Viora`.

> Unofficial software; not affiliated with Roblox or Discord. Local FastFlag changes depend on Roblox's allowlist.
