Violetstrap v0.7 — Activity & Presence
====================================
Base: v0.6.2 session-tracking hotfix (all fixes preserved).

GAME HUB
- Track indicator says when game observation is paused, awaiting a place ID, or active.
- Sort game cards by time, most recently played, or name.
- Show only favourites, optionally combined with a text search.
- Search/sort controls are on the same page (no additional sidebar clutter).
- View 7- or 30-day playtime charts for the selected Roblox experience.
- New 7/30-day observed total, approximate average session and longest completed
  *saved* session. (Old session logs are bounded at 500.)
- Chart keeps its vertical scale proportional and horizontally scrolls at 30 days.
- Offline icon caching and public Roblox game artwork from v0.6.1 remain intact.

FAVOURITES & QUICK LAUNCH
- Recently opened favourites appear first (also on the home dashboard).
- Counts requests to open each favourite's official Roblox game page.
- Copy the selected game's official link to the clipboard without opening it.
- Launch links are generated only as https://www.roblox.com/games/<placeId>.
- These launches are requests to open a web page, not proof Roblox was joined.

DISCORD RICH PRESENCE
- Per-game template buttons: Playing / Grinding / Exploring.
- Live editor preview expands {game} using the selected experience's name.
- Switch any per-game override off without deleting its saved text and asset key.
- Existing v0.6 game-specific overrides default to enabled.
- AFK status and "hide game names" preferences continue to take precedence.
- No Discord credentials, Roblox cookies or private server identifiers are used.

COMPATIBILITY
- Existing local settings are loaded from %LOCALAPPDATA%\Violetstrap.
- v0.6.2 Roblox-window lifecycle and session stopping logic retained.
- v0.5.2 GIF splash, visual themes, FastFlags, performance presets, and
  local account logic retained.

TEST STATUS
- XAML XML, unique element-name, button event-handler, project and ZIP
  consistency checks can be run without Windows.
- Windows compilation and functional testing of RPC/UI were NOT possible in
  this environment. Run build-windows.bat and confirm on your own Windows PC.
