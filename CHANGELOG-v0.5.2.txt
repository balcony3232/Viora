VIOLETSTRAP v0.5.2 — SPLASH & USABILITY UPDATE
17 October 2026

NEW — COMPACT STARTUP SPLASH
• Replaced the full-window overlay with a separate centered, floating WPF window.
• Three widths: Small (460x340), Medium (560x395), Large (660x460).
• Dark violet card, rounded corners, subtle shadow and a small close/skip control.
• Logo banner, loading text, animated status dots and optional fades.
• Splash is displayed after signing into Violetstrap (including remembered sign-in), NOT in Roblox's game loading screen.

NEW — CUSTOM IMAGE AND GIF
• Default logo art, PNG/JPEG image, or animated GIF in the splash banner.
• Supports GIF timing from file metadata and frame placement/disposal (pure WPF, no NuGet package).
• GIFs loop in both the live editor and separate floating preview.
• Image size is restricted to 12 MB; GIFs to 15 MB, <=240 frames, <=1920x1080, and a composited total of <=60 million frame-pixels.
• Selected files are validated and copied to %LOCALAPPDATA%\Violetstrap\splash when saved.
• Optional separate PNG/JPG background under the media area; removable at any time.

NEW — SPLASH SCREEN EDITOR
• Personalise > Splash Screen dedicated page; also reachable from Appearance and Utilities.
• Enable / disable, Default / Image / GIF, Small / Medium / Large.
• Duration slider: 0.5 to 10 seconds.
• Show/hide logo and loading text.
• Skip automatically when Roblox is running, if requested.
• Fade in and out, with 150/300/500ms selectors. Existing Reduce Motion preference disables fades.
• Live media preview and a Play preview button that opens the actual floating window.
• Save changes commits local settings; Reset defaults only changes the editor until saved.
• Previous v0.5.1 background is migrated as the new background where it exists.

RETAINED FROM v0.5.1
• Five-entry grouped sidebar: Overview, Optimise, Workspace, Activity, Personalise.
• Roblox saved FPS cap and graphics quality controls in Optimise > Performance, including backup/restore and the same limitations.
• FastFlag Explorer, experimental presets, Asset Studio, profiles, statistics, and optional Discord Rich Presence.
• Existing local account and settings folder; no new account signup required.

LIMITATIONS / TESTING
• The source structure and XAML handlers have been checked. It has not been compiled or runtime-tested on Windows here.
• GIFs with unusual disposal semantics or very complex animation should be tested using Play preview.
• No changes to Roblox's own start/loading screen, account, anti-cheat, or client executable.
• Tests to run: build-windows.bat; small default splash; import GIF and Preview; Save; restart; Skip when Roblox running; Restore default.
