Violetstrap v0.3 — Personal workspace

- Explicit dark root/window surface and WPF dark-window caption request
- Purple main/secondary/nav buttons and dark ComboBox/dropdown theme
- Local-only signup and login with salted PBKDF2 password hash
- Optional stay-signed-in flag (no cloud service)
- Personal "Hello, username" welcome dashboard and quick tools
- Statistics: observed Roblox playtime, sessions seen, launch requests and longest observed session
- Local five-second process polling; 30-second saves; stops when Violetstrap closes
- Purple-logo startup splash and custom PNG/JPG background settings with preview/reset
- Existing v0.2 workspace, flags, profiles, performance presets, and asset tools preserved

Build not executed in generation environment. Test on Windows 10/11 with .NET 8 SDK.
